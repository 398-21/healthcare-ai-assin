## 1. 项目总体思路

### 1.1 统一的临床问题

> **利用入 ICU 前 48 小时的常规监测与化验数据，能否同时识别"谁有院内死亡风险"和"谁会长期占用床位"，从而支持 ICU 的风险分层与床位规划决策，并超越现行床旁评分（SAPS-I / SOFA）的表现？**

两个预测任务共享同一套数据管线（清洗 → 特征聚合 → 划分），但对应**不同的使用者、不同的行动、不同的错误代价**，因此主指标各不相同。这个结构直接回应课程要求的三个问题：谁来用预测？预测改变什么行动？哪种错误更昂贵？

### 1.2 两个预测任务

| | 任务 1：院内死亡预测 | 任务 2：延长住院预测 |
|---|---|---|
| 目标变量 | `In-hospital_death`（数据集直接给的 0/1） | 由原始列 `Length_of_stay`（天数）**派生**的二分类：`Length_of_stay > T`（0/1，T 待定，见 §6.2） |
| 正类比例 | 14.2%（1,707/12,000） | T=7：65%；T=14：30% |
| 使用者 | ICU 主治医师 / 快速反应团队 | 床位协调员 / 出院规划团队 |
| 触发的行动 | 上级复核、升级监护、提前家属沟通 | 启动出院规划、预留后续病房、排班预测 |
| 更昂贵的错误 | **漏诊（FN）**：漏掉将死亡的病人 | 两侧代价相对对称，但概率本身要准 |
| 主指标 | **AUPRC**（辅以 AUROC、min(Se,PPV)） | **AUROC + 校准**（calibration curve、Brier score） |

### 1.3 核心故事线

现行临床评分在本数据集上只有 AUROC≈0.64（详见 §5.5 完整基线梯子）。
文献中机器学习模型在此数据集上可达 AUROC 0.83–0.86。项目的叙事：**"床旁评分只有 0.64，我们从同样 48 小时的原始数据中做到 0.85——多出来的性能来自哪里（时序趋势？测量行为？非线性交互？），并用可解释性方法给出答案。"**

## 2. 数据概况（已实测核对）

- `icu_records/`：12,000 个患者文件，长表格式 `Time,Parameter,Value`，Time 为入 ICU 后经过时间（00:00–47:59），平均每份约 440 行观测。`Value = -1` 表示缺失。
- `outcomes.csv`：每人一行——`RecordID, SAPS-I, SOFA, Length_of_stay, Survival, In-hospital_death`。
- 静态描述符：Age、Gender、Height、Weight、ICUType（1 冠心病 / 2 心外恢复 / 3 内科 / 4 外科）。
- 37 个时变变量，**可得性差异极大**（抽样 1,500 份实测）：

| 层级 | 变量 | 覆盖率（%患者） | 每人观测次数（中位） |
|---|---|---|---|
| 高频生命体征 | HR, Temp, GCS, Urine | 96–98% | 15–58 |
| 常规化验 | BUN, Creatinine, HCO3, Na, K, Mg, Glucose, WBC, Platelets, HCT | ~98% | 3–5 |
| 血压（二选一） | 无创 NI* 86% / 有创 *ABP 71% | — | 28–52 |
| 血气 | pH, PaCO2, PaO2 | 77% | 7–8 |
| 呼吸支持 | FiO2 67%, MechVent 64% | — | ~12 |
| 肝功能 | ALT, AST, Bilirubin, ALP, Albumin | 40–44% | 1–2 |
| 稀疏 | Lactate 55%, SaO2 46%, RespRate 28%, TroponinT 21%, Cholesterol 8%, TroponinI 4% | — | 1–4 |

结局分布：院内死亡率 14.2%；LOS 中位 10 天、均值 13.4、最大 295（严重右偏）；`Survival ≤ 7` 天的早期死亡 919 例。

## 3. 已验证的数据陷阱（预处理必须逐条处理）

以下每一条都已在数据上实际验证过，报告中应作为数据质量章节呈现：

1. **`MechVent` 只有 1，从无 0。**（抽样 600 份、4,569 条记录全为 1。）"没有记录"= 未上机械通气，**不是缺失**。编码方式：`ever_mechvent`（0/1）+ 首次上机时间/时长类特征。绝不能按缺失填补。
2. **`Urine = 0` 是真实的少尿/无尿，不是缺失。**（实测 517 条真实 0 值，-1 为 0 条。）少尿是最强的预后信号之一，误当缺失会丢掉关键信息。
3. **生理不可能值需裁剪。** 实测发现：Temp 最低 −17.8°C；Height 最低 1.8 cm（单位错误，疑为米）；HR / SysABP / DiasABP 存在 0 值。方案：为每个变量制定生理合理范围表（引用文献或临床常识），范围外置为缺失；Height<100 的先尝试 ×100 修复再判断。
4. **`Length_of_stay` 有 167 例为负数。** 从两个任务中剔除并在报告中说明。
5. **`Parameter` 列存在 NaN 行**（800 份文件中 148 行），读取时过滤。
6. **有创/无创血压是"二选一"的平行变量**（SysABP 71% vs NISysABP 86%）。方案：合并为统一血压特征（优先有创），同时保留 `has_arterial_line`（0/1）指示——是否置动脉导管本身反映病情严重度。
7. **`Weight` 同时出现在 00:00 静态段和后续时变段**，注意去重与清洗（-1 处理）。
8. **年龄 ≥90 岁统一记为 90**（去标识化截断），解释高龄段分布时注意。

**缺失即信息（missingness is informative）**：医生给谁开乳酸、肝功能、肌钙蛋白，本身就是病情判断。除填补外，**必须为低覆盖率变量构建"是否被测量"指示特征和测量频次特征**。文献中这类特征常比填补值本身更有预测力，也是可解释性分析的好素材。

## 4. 数据管线设计

### 4.1 从长表到宽表（特征聚合）

每位患者的不规则时序 → 固定长度特征向量：

- **静态**：Age、Gender、ICUType（one-hot）、清洗后的 Height/Weight/BMI。
- **每个时变变量**：min / max / mean / median / 首值 / 末值 /（末值−首值）趋势 / 标准差 / 测量次数。
- **时间窗分段**：0–24h 与 24–48h 各算一遍关键统计量，其差值捕捉"恶化 vs 好转"轨迹（例：GCS_24h后 − GCS_24h前）。
- **缺失指示**：`measured_<var>`（0/1）与 `count_<var>`，至少覆盖 Lactate、Troponin、肝功能、血气等低覆盖变量。
- **衍生临床特征（可选加分）**：PaO2/FiO2 比值（呼吸衰竭指标，即 SOFA 呼吸项）、BUN/Creatinine 比、脉压差、休克指数（HR/SysABP）、尿量总和（48h 总尿量）。

### 4.2 缺失填补

- 树模型（XGBoost/LightGBM）：可直接原生处理 NaN，**首选方案，避免填补引入偏差**。
- 逻辑回归：中位数填补 + 缺失指示列；报告中说明并做敏感性检查。
- 禁止用全数据集统计量填补后再划分（泄漏）——填补参数只从训练集估计。

### 4.3 数据划分与评估协议

- 按患者划分 train / validation / test（如 70/15/15），**按结局分层**保证各集死亡率一致；同一患者绝不跨集。
- 超参调优只在 train+validation 上做（交叉验证或固定验证集）；**test 集只在最终评估时碰一次**。
- 报告 test 集指标时附 95% 置信区间（bootstrap 1,000 次重采样）。
- 两个任务共用同一套划分，便于横向比较。

## 5. 指标选取与理由（答辩重点）

### 5.1 原则

没有单一指标是"最恰当"的。我们按**每个任务的使用者如何消费预测结果**来分工使用指标：**AUROC 看排序能力，AUPRC 看报警质量，校准看概率可信度**。

### 5.2 任务 1（死亡预测）：主指标 AUPRC

- **AUROC** = 随机抽一个死亡病人和一个存活病人，模型给前者更高风险分的概率。对类别比例不敏感——这是它可跨文献比较的优点，也是它的陷阱：假阳性率的分母是全体阴性，阴性占 86% 时，假阳性大量增加在 ROC 上仍显得温和，导致"AUROC 好看但报警器没人信"。
- **AUPRC** 直接刻画 precision（报警中多少是真的）与 recall（真死亡中抓住多少）的权衡，假阳性直接进 precision 分母，在 14.2% 患病率下更诚实。代价：AUPRC 随患病率变化，数字必须与患病率基线（0.142）对照解读，不能跨数据集直接比。
- **两者都报**：AUPRC 为主（贴合临床使用），AUROC 为辅（与 SAPS/SOFA 基线及文献可比）。
- **工作点选择**：漏诊代价（生命）≫ 误报代价（一次多余查房），因此不用默认 0.5 阈值，而是**在验证集上按 recall ≈ 0.80 定阈值**，在 test 集报告该点的 sensitivity / PPV / specificity。
- **附加**：报告 PhysioNet 2012 挑战赛官方指标 **min(Sensitivity, PPV)**，可与当年参赛队伍直接对标。

### 5.3 任务 2（延长住院）：主指标 AUROC + 校准

- 选 T=14 时正类约 30%，类别不算悬殊，AUROC 的失真问题不突出。
- **必须加校准分析**（calibration curve + Brier score）：床位规划消费的是概率本身（把各病人的概率加总估计"下周长住床位数"），只会排序、概率不准的模型对资源规划无用。校准是 AUROC/AUPRC 都不覆盖的维度。
- 若最终模型概率失准，用 Platt scaling / isotonic regression 在验证集上校准后再评估。

### 5.4 为什么 LOS 做二分类而不是回归

1. **决策形式是离散的**：床位协调的动作（启动出院规划/预留病房/纳入长住名单）是做与不做，"78% 概率住超两周"比"预计 13.2 天"更贴近决策。
2. **分布不允许**：LOS 中位 10、最大 295，严重右偏；回归损失被极端值主导，而极端值多由数据外因素（社会因素、转院）决定。RMSE 既做不好也无临床解释。
3. 这个选择本身要在报告中论证——展示指标选择由临床决策驱动，是评分点。

### 5.5 Baseline 是一个梯子，不是一个数字

小组容易走偏的地方：把 baseline 理解成"要去查出来的那个标准答案数字"，然后把项目做成刷榜。**baseline 是论证工具**——每一级回答一个不同的问题，缺哪一级，答辩时对应的那个问题就答不上来。

| 层级 | 内容 | 它回答的问题 |
|---|---|---|
| **L0** | 随机 / 无信息（AUPRC = 患病率） | 模型到底学到东西了吗？ |
| **L1** | 单变量（只用年龄、只用最低 GCS、只用最高 BUN） | 值得建这么复杂的管线吗？ |
| **L2** | 临床评分 SAPS-I / SOFA | **比医生现在床旁用的工具强吗？**（临床意义在这一级） |
| **L3** | 自建的简单模型（少数特征的逻辑回归） | 上 GBDT / 深度学习的复杂度值得吗？ |
| **L4** | 文献最优（此数据集 AUROC 0.83–0.86） | 我们做到领域水准了吗？ |

**快速实测结果 —— 任务 1（院内死亡）**（测试集 n=1,800；仅 5 个粗特征、未做生理值裁剪、未调参——正式管线须重跑）：

| 层级 | AUROC | AUPRC |
|---|---|---|
| L0 随机 | 0.500 | 0.142 |
| L1 只用 Age | 0.610 | 0.197 |
| L1 只用 GCS_min | 0.602 | 0.173 |
| L1 只用 BUN_max | **0.650** | 0.222 |
| L2 SAPS-I | 0.657 | 0.262 |
| L2 SOFA | 0.642 | 0.274 |
| L3 5 特征逻辑回归 | **0.738** | **0.312** |

两个可直接写进幻灯片的发现：

1. **单变量 BUN_max（0.650）与 SAPS-I（0.657）在统计上无法区分**（差距 0.007 ≪ 置信区间宽度 ±0.035）。SAPS-I 十四项加权求和的判别力 ≈ 看一眼最高血尿素氮。这正是挑战赛存在的动机：现行评分是为**群体风险分层**设计的，不是为个体化预测优化的。官方论文里那个"SAPS-I = 32 却活着出院"的病例是同一件事的另一面。
2. **L3（5 特征逻辑回归，0.738）才是真正要打败的对手，不是 SAPS-I。** 如果最终 GBDT 只到 0.75，说明整套复杂管线相对 5 个特征几乎无增益，复杂度无法辩护。目标应对齐 L4（0.83–0.86）。

**快速实测结果 —— 任务 2（LOS > 14 天）**（按 §6.3 方案 A 排除院内死亡病例，n=10,126，正类 30.3%；测试集 n=1,519。L1/L3 尚未跑，待正式管线补齐）：

| 层级 | AUROC | AUPRC |
|---|---|---|
| L0 随机 | 0.500 | 0.303 |
| L2 SAPS-I | 0.611 | 0.393 |
| L2 SOFA | 0.609 | 0.407 |

⚠️ **两个任务的 AUPRC 绝对值不可直接横向比较。** 任务 2 的 SOFA AUPRC（0.407）看似远高于任务 1（0.274），但任务 2 的随机基线本身就是 0.303 而任务 1 只有 0.142。按相对基线的提升算：任务 1 = +0.13，任务 2 = +0.10——实际上任务 1 的提升更大。**AUPRC 必须始终与本任务自身的患病率基线并列呈现**，这是 §5.2 中"AUPRC 随患病率变化"的具体体现。另注：临床评分在 LOS 任务上的 AUROC（≈0.61）低于死亡任务（≈0.65），符合预期——SAPS/SOFA 本就是为死亡风险设计的，不是为住院时长设计的。

### 5.6 指标计算的实现细节（会影响结果正确性，全组必须统一）

**基线分数如何算**：AUROC/AUPRC 只关心**排序**，与数值尺度无关，因此可直接把 SAPS-I / SOFA 原始分数当作预测分数传入。已验证：对 SOFA 做 logistic 变换或三次方，AUROC/AUPRC 一个小数位都不变（0.6372 / 0.2531）。

```python
from sklearn.metrics import roc_auc_score, average_precision_score
roc_auc_score(y_true, saps_score)            # 无需转成概率
average_precision_score(y_true, saps_score)
```

**三个必须注意的坑：**

1. **⚠️ baseline 必须在与模型完全相同的测试集上重算。** 全量 12,000 条算出的 SAPS-I AUROC = 0.645，同一分数在 1,800 人测试集上 = 0.657，差 0.012。拿全量数字与模型的测试集数字对比是错误的。
2. **⚠️ AUPRC 统一用 `average_precision_score`，禁止用 `auc(recall, precision)`。** 两者在平局多时结果不同（实测 SOFA 上差 0.013）；梯形插值在 PR 曲线上有已知的乐观偏差。全组不统一，组员之间的数字对不上。
3. **平局（ties）问题**：SAPS-I 仅 37 个不同取值、SOFA 仅 24 个，却要排序 12,000 人——大量病人共享同一分数，组内无法排序。这本身压低了离散评分的表现，是"离散评分 vs 连续概率模型"差距的来源之一，值得在讨论章节展开。

### 5.7 指标不等于结论：三条纪律

**指标是证据，不是结论。** 课程 slides 原文："A higher model score is not enough without a defensible clinical and analytical story"，评分线是 `clinical question → data → preprocessing → model comparison → metric → recommendation`——没有一环写着"取得最高分数"。40% 里只有 20% 是代码管线，另外 20% 在展示答辩与同伴互评。

1. **差异要看置信区间，不看小数点。** 测试集 n=1,800 时 AUROC 的 bootstrap 95% CI 宽约 ±0.035（实测 SAPS-I: 0.657 [0.621, 0.690]）。"我们 0.851 比别组 0.847 更好"在统计上是噪声，答辩时站不住；而 0.85 vs 0.65 远超区间宽度，才是能理直气壮讲的结论。**所有报告的指标都必须带 CI。**
2. **这两个指标看不见三样东西**，而它们决定模型能否真的被使用：**校准**（概率准不准 → 影响家属沟通与资源加总）、**工作点表现**（选定阈值后的 Se/PPV → 医生实际只用一个阈值）、**子群表现**（整体 0.85 可能掩盖某类 ICU 上仅 0.6）。
3. **参考文献**：官方论文 Silva et al., *Predicting In-Hospital Mortality of ICU Patients: The PhysioNet/CinC Challenge 2012*（[PubMed 24678516](https://pubmed.ncbi.nlm.nih.gov/24678516/)、[数据集主页](https://physionet.org/content/challenge-2012/1.0.0/)）。官方以 SAPS-I 为 baseline，Event 1 得分 0.3125，当年冠军 0.5353；官方评分脚本 [genresults.m](https://physionet.org/content/challenge-2012/1.0.0/genresults.m) 中 `score1 = min(Sensitivity, PPV)`。

## 6. 待小组决策的开放问题

### 6.1 【已定原则，待确认】SAPS-I / SOFA 的角色

- **它们是什么**：真实临床使用的病情严重度评分。SAPS-I（1984）：入 ICU 前 24h 内 14 个生理指标最差值查表加总；SOFA（1996）：呼吸/凝血/肝/循环/神经/肾六个器官系统各 0–4 分加总（Sepsis-3 定义即基于 SOFA 变化）。**其原料就是我们记录文件里的变量**，由数据提供方回顾性算出。
- **应当**：作为"现行临床实践"基线对比；作为 SHAP 结果的合理性检验参照（模型 top 特征应与 SOFA 关注的器官指标有重合）。
- **不应当**：作为模型输入特征。注意：严格说这**不是**信息泄漏（分数在预测时点可得，文献也有人用），真正的理由是——(1) 它们是输入原始变量的衍生量，信息冗余；(2) 用了它们，"我们打败了 SAPS"的对比就不再公平，故事被摧毁；(3) 课程要求从原始数据自建管线。
- **绝对禁止碰的**：`Survival`、`Length_of_stay` 作为特征（直接编码结局）。

### 6.2 【待决策】延长住院的阈值 T

- T=7：正类 65%——"超过 7 天"是多数情况，称"延长"名不副实。
- **T=14：正类 30%——初步推荐**。类别更平衡，"两周"对应更明确的长住概念。
- 决策依据：阈值应对应真实运营规划周期（病房排班/择期手术多按周规划），用 LOS 分布数据支持选择。**咨询课上与老师确认。**

### 6.3 【待决策】LOS 任务中死亡病人的处理（competing risk）

死亡会"截断"住院时长（人死了住院即结束），短 LOS 里混着"恢复快出院"和"很快死亡"两类完全相反的病人。候选方案：
- A. LOS 任务**排除院内死亡病例**，问题变为"存活者中谁会长住"（初步推荐，最干净）；
- B. 目标定义为"存活且 LOS>T"，死亡者归为负类（需论证合理性）；
- C. 三分类：早死 / 短住存活 / 长住。

报告中无论选哪个都要明确写出这个 competing risk 问题——讲清楚它本身就是加分点。

### 6.4 【待决策】是否做第三个分析（超出最低要求）

候选（按性价比排序）：
1. **早期预测对比**：仅用前 24h 数据重训死亡模型，对比 48h 版本——"提前 24 小时损失多少性能？"直接关系干预窗口，临床意义强，管线复用度高。
2. **子群公平性**：按 ICUType 和年龄段分别报告性能，某类 ICU 上显著更差即为有意义发现。
3. LSTM/GRU 时序模型（仅当确有余力，见 §7）。

## 7. 建模路线（复杂度递进，每一步的增量必须被证明）

1. **逻辑回归（L1/L2 正则）**——可解释的机器学习基线。与 SAPS/SOFA 的差距展示"同样是线性思路，特征工程带来多少提升"。
2. **梯度提升树（XGBoost 或 LightGBM）**——预期主力模型。此类不规则采样聚合后的表格数据上，GBDT 几乎总是最强，且原生处理缺失。
3. **（可选）LSTM / GRU / Transformer 直接吃时序**——只有当它在验证集上确实超过 GBDT 才纳入正文；若没超过，如实汇报"额外复杂度未带来收益"——**这同样是合格的结论**，且完全符合课程"复杂度必须被证明"的要求。

每个任务、每个模型使用同一套划分与指标，汇总成一张**主结果表 = §5.5 的完整基线梯子 + 自建模型**：行 = {L0 随机, L1 单变量×3, L2 SAPS-I, L2 SOFA, L3 简单 LR, 完整 LR, GBDT, (RNN)}，列 = {AUROC[95%CI], AUPRC[95%CI], min(Se,PPV) 或 Brier}。这张递进表本身就是一段完整论证——每加一层复杂度收益是多少、值不值——直接对应课程要求的 "model comparison" 环节。

## 8. 可解释性方案（课程硬性要求，每个模型都要有）

- **逻辑回归**：标准化系数直接解读。
- **GBDT**：**SHAP**——全局（summary plot：哪些特征驱动死亡风险）+ 个例（force/waterfall plot：这位病人为什么被判高危），把技术输出翻译成临床语言。
- **合理性检验**：SHAP top 特征应符合医学常识（GCS 低、乳酸高、尿量少、BUN/肌酐高、高龄 → 高危），并与 SOFA 的器官维度对照。**若模型依赖临床上讲不通的特征，视为泄漏/伪影信号，必须追查**——这个检查过程本身写进报告。
- **缺失指示特征的解读**：若 `measured_Lactate` 等测量行为特征进入 top 特征，讨论"模型学到的是生理还是医生的行为"——这是高质量的讨论章节素材。
